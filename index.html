🤖 Prompt de Referencia para XOLO (Solo para Maestro)

⚠️ NOTA: XOLO ya conoce el tema de esta misión. Este prompt es SOLO de referencia en caso de emergencia técnica: 
Quiero aprender qué es el sesgo algorítmico y cómo puede surgir solo por entrenar a una IA con datos incompletos o desequilibrados. Explícame primero qué significa “sesgo” en un modelo y por qué no siempre es intencional. Luego enséñame a preparar un entrenamiento sesgado usando ai.switch_function(Card) y ai.learn_object(1), eligiendo tarjetas o ejemplos que favorezcan un tipo de objeto. Después muéstrame cómo revisar el aprendizaje con ai.get_learn_data() y cómo diseñar una prueba controlada para demostrar que el modelo responde mejor a un caso que a otro. Incluye una explicación clara sobre por qué esto es importante en el mundo real (ej: reconocimiento facial, contrataciones).

⚡ Puntos Esenciales de la Misión

🎓

Concepto Clave

Sesgo algorítmico: Es cuando una IA toma decisiones injustas porque aprendió de ejemplos incompletos o desequilibrados, como si un juez solo escuchara a una de las partes.

🔧

Habilidad Técnica

Usar la cámara inteligente para entrenar al robot con ejemplos desiguales y ver cómo afecta sus decisiones.

🧪

Experimentación

Probar con diferentes cantidades de tarjetas de entrenamiento para entender las limitaciones del reconocimiento.

Interacción con XOLO

🚨 Resolución Rápida de Problemas

  • Si los alumnos no pueden ingresar a Gnius Space: Activa XOLO SOS en xolo.gnius.club para continuar la misión sin interrumpir la clase.

📊 Diapositiva 3: Brain Spark

1. 💬 Pide a XOLO que te ayude a crear:

"Ayúdame a idear en Python un experimento donde el XGO demuestre “preferencias injustas” por un tipo de tarjeta u objeto debido a un entrenamiento sesgado. Quiero que el proyecto sea como una demostración científica: hipótesis → entrenamiento → pruebas → resultados. Después genera el código en Python para ejecutarlo, de acuerdo a tu entrenamiento con el robot XGO y Micro:bit, e incluye una plantilla simple para registrar resultados (tabla de cuántas veces reconoce A vs B)."

2. 🔬 Experimenta y descubre con tu programa:

  • ¿El robot reconoce la tarjeta que más veces vio durante el entrenamiento?
  • ¿Qué sucede si intentas que el XGO reconozca un objeto del que solo le mostraste una imagen?
  • ¿Funciona igual el reconocimiento con mucha luz vs. poca luz después del entrenamiento sesgado?
  • Si el robot toma decisiones basadas en datos incompletos, ¿cómo se relaciona esto con el concepto de sesgo algorítmico?
  • ¿Por qué es un problema de ética de datos si una IA de contratación solo ha visto currículums de un solo tipo de persona?

¡Es hora de crear nuestra propia demostración científica! Vamos a idear un experimento donde el XGO demuestre una "preferencia injusta". El flujo es: idear con XOLO, definir el VIBE, recibir el GCS, pasarlo a MakeCode y experimentar. Por ejemplo, podrían entrenar al robot para que solo se emocione con tarjetas rojas y ignore las azules, demostrando cómo un entrenamiento desigual crea un comportamiento sesgado. Sigan las preguntas de experimentación para registrar sus resultados. Recuerden entregar el hardware con cuidado al final. Si tienen errores o dudas, pregúntenle a XOLO, él los ayudará a depurar.
